# Yesterdays Desktop

> [!WARNING]  
> Early-stage, pre-release software. You have been warned.

This is a [Tauri](https://tauri.app/) + [Svelte](https://svelte.dev/) + [Bootstrap](https://getbootstrap.com/) app for interfacing with the [Yesterdays](https://docs.yesterdays.maprva.org/) API v2.

## Installation

Download the latest version from our [Releases page](https://github.com/MapRVA/yesterdays-desktop/releases) to get started. Arch Linux users can [install the package from the AUR](https://aur.archlinux.org/packages/yesterdays-desktop-bin).

## Development

Requires [Bun](https://bun.sh/) and the [Tauri prerequisites](https://tauri.app/start/prerequisites/) for your platform.

```sh
bun install
bun run tauri dev
```
